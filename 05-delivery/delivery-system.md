# Service Delivery System — Meridian Research & Advisory

> Version 1.0 · Owned by Dispatch (Delivery Ops) + Kepler (PM) · End-to-end engagement lifecycle.

## Objective

Deliver every engagement predictably: workspace → requirements → milestones →
production → QA → delivery → feedback → archive. Fully automated where possible,
QA-gated before any client-facing output.

## Engagement lifecycle

```
 SIGN → SETUP → KICKOFF → DELIVERY → QA → DELIVER → FEEDBACK → ARCHIVE
```

| Phase | Owner | Output | Gate |
|---|---|---|---|
| **Sign** | Vector | Signed MSA/SOW + payment setup | Legal review done, owner executed |
| **Setup** | Dispatch | Workspace, folders, access, invoice, calendar | Workspace checklist complete |
| **Kickoff** | Kepler + Halo | Requirements brief, milestones, SLA | Client confirms scope |
| **Delivery** | Dispatch routes specialist agents | Draft deliverables per milestone | Milestone checklist |
| **QA** | Norm | QA report, fixes | QA gate pass (≥ threshold) |
| **Deliver** | Dispatch | Final deliverables + client comms | Client acknowledges |
| **Feedback** | Halo | CSAT/NPS + lessons | Feedback recorded |
| **Archive** | Mnemos | Knowledge stored, workspace archived | Archive checklist |

## Workspace standard

Every engagement gets: project folder, shared client docs, deliverable staging,
QA log, and client portal link (shared dashboard). Naming:
`MRA-<client>-<service>-<YYYYMMDD>`.

## Requirements collection (Kepler)

- Kickoff brief: objectives, success metrics, constraints, data access, timeline.
- Requirements stored in engagement record + knowledge base; frozen after kickoff (change control for scope changes).

## Milestones & progress

- Every service has a milestone template (`11-knowledge/templates/milestone-template.md`).
- Progress tracked on the engagement record + client dashboard.
- Weekly client update (status report) for engagements > 2 weeks.

## Delivery KPIs

| KPI | Definition | Target |
|---|---|---|
| On-time delivery | Milestones met on date | ≥ 95% |
| QA pass rate | Deliverables passing first QA gate | ≥ 90% |
| Client satisfaction | CSAT (1-5) | ≥ 4.5 |
| Churn (subs) | Canceled subscription revenue ÷ total | ≤ 5%/mo |
| Delivery margin | (Revenue − delivery cost) ÷ revenue | ≥ 80% |
| Time-to-first-value | Sign → first deliverable | ≤ 14 days |

## Escalation

- Scope change / missed input SLA → Kepler → Dispatch → COO.
- Client risk (satisfaction, scope, payment) → Halo → COO within 24h.
- Legal/liability question → Amicus (Legal).
