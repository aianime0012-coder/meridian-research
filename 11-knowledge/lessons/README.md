# Lessons Learned — Meridian Research & Advisory

> Owned by Mnemos (Knowledge) · Every engagement and every failed experiment appends here. Feeds the improvement engine.

## How to add a lesson

1. After any engagement completion, QA rework, churn, or failed experiment, write one lesson note.
2. Format:

```markdown
## <YYYY-MM-DD> — <Topic>
**Project / engagement:** <ref>
**What happened:** <one paragraph>
**Root cause:** <one line>
**Lesson:** <actionable, reusable rule>
**Applied to:** <SOP / template / workflow / agent instruction>
```

3. Link the note to the relevant SOP/template and to `13-improvement/daily-retro.md`.

## Rules

- One lesson per note; keep it actionable.
- No lesson is added without a follow-up owner + date.
- Review the lessons index monthly (with COO) for pattern detection.
