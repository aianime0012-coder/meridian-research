# Experiment Tracker — Meridian Research & Advisory

> Version 1.0 · Owned by Euclid (Analytics) + COO · Every change is an experiment; every experiment is measured.

## Rules

1. One variable at a time.
2. Define the metric and target before starting.
3. Small, reversible, time-boxed (1–4 weeks).
4. Log results; ship wins, kill losers, record learning.

## Experiment template

```markdown
## EXP-<NN> — <Title>
**Hypothesis:** <if we change X, Y will change by Z>
**Metric:** <KPI + baseline>
**Duration:** <start–end>
**Variants:** <control / treatment>
**Owner:** <agent>
**Status:** planned | running | won | lost | inconclusive
**Result:** <numbers>
**Decision:** <keep / rollback / scale>
```

## A/B discipline

- Minimum sample: ≥ 40 per variant for outreach; ≥ 200 sessions for web.
- Statistical noise acknowledged: no claim without n.
- Results feed back into playbooks and `00-company/decision-log.md`.
