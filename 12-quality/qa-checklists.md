# QA Checklists — Meridian Research & Advisory

> Version 1.0 · Owned by Norm (QA) · Run per artifact type. Copy into the QA log for each item reviewed.

## General checklist (all client-facing output)

- [ ] Client name spelled correctly; correct company/contact references
- [ ] Date and version on the cover; document ID assigned
- [ ] File naming convention: `MRA-<client>-<service>-<YYYYMMDD>`
- [ ] Disclosure footer present: "Prepared by Meridian Research & Advisory. Analysis is AI-assisted and human-reviewed."
- [ ] No jargon without definition; tone matches brand (clear, evidence-first, no hype)
- [ ] No guaranteed-outcome or false-advertising language
- [ ] Brand template applied (colors, typography, logo)

## Report / research deliverable checklist

- [ ] Executive summary answers the client's question in the first page
- [ ] Methodology section states approach and limitations
- [ ] Every factual claim has a named, dated source with working link
- [ ] No fabricated sources or URLs
- [ ] Numbers internally consistent (totals match parts; % add up)
- [ ] Uncertain findings labeled with confidence level
- [ ] Recommendations ranked and actionable, with rationale
- [ ] All promised sections present; appendix with source list
- [ ] Peer-review pass by independent agent (no self-QA)

## Proposal / SOW checklist

- [ ] Problem statement mirrors discovery notes
- [ ] Scope, deliverables, and exclusions explicit
- [ ] Milestones, dates, and fees match pricing policy
- [ ] Subscription attach included per bundling rule (or reason documented)
- [ ] Legal template used; placeholders filled; compliance flags resolved
- [ ] Terms: payment schedule, acceptance, changes, termination
- [ ] QA score ≥ 90 before send

## Email / outreach checklist

- [ ] Physical postal address present (CAN-SPAM)
- [ ] Unsubscribe/opt-out mechanism present
- [ ] First line personalized with verified signal (no generic mass mail)
- [ ] No deceptive subject line; volume limits respected
- [ ] Links verified working

## Website / public content checklist

- [ ] Privacy / Terms / Cookie links reachable from every page
- [ ] Consent banner present where required
- [ ] Analytics privacy-friendly; no sensitive PII captured
- [ ] Accessibility basics (contrast, alt text)
- [ ] Claims source-linked or clearly labeled as opinion

## Financial / invoice checklist

- [ ] Correct client, invoice number, dates, line items, totals
- [ ] Tax fields as required by jurisdiction
- [ ] Payment terms and methods clear
- [ ] Matches signed SOW/contract amounts

## Legal document checklist

- [ ] Template from library used; no invented clauses
- [ ] Placeholders resolved or flagged
- [ ] Compliance review by Solon completed
- [ ] Executed by owner only (never agent-executed)
- [ ] Filed in contract register

## Security / data checklist

- [ ] No secrets, keys, or PII beyond necessary in output
- [ ] Client data handling per DPA; least privilege applied
- [ ] No sensitive data in logs or dashboards without need
