# Meridian Research & Advisory

**"Decisions beyond the horizon."**

An AI-first global research & consulting firm, operated 24/7 by an autonomous
agent workforce running on **Meridian OS**. The human owner is the sole
shareholder; every other function is delegated to AI agents wherever legally and
technically possible.

This repository is the **operating system** of the company: company architecture,
department blueprints, agent definitions, SOPs, automation workflows, CRM schema,
sales/marketing/finance/legal systems, dashboards, and the continuous-improvement
engine.

## Operating principles

1. **Never stop at planning** — every phase produces working artifacts.
2. **Research first, verify, document decisions** — no hallucination.
3. **Maximize recurring revenue** — subscriptions and retainers over one-offs.
4. **Reduce manual work** — anything that repeats becomes an automation.
5. **Compliance by design** — legal, tax, KYC/AML, platform rules are never bypassed.
6. **Human = shareholder, not employee** — the owner approves legally binding acts only.
7. **Think in decades** — scalable, portable, documented systems.
