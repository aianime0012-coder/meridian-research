# Sales System — Meridian Research & Advisory

> Version 1.0 · Owned by Vector (Sales) + Ranger (Lead Gen) · Pipeline, playbooks, KPIs.

## Objective

Turn scored opportunities into signed, paying, retained clients — deterministically,
with every stage measured and every KPI tracked.

## Pipeline stages (CRM)

```
lead → sql → discovery → proposal → negotiation → won
                                        └──→ lost (with reason)
```

| Stage | Definition | Entry criteria | Exit action |
|---|---|---|---|
| **Lead** | Enriched, scored company | fit score recorded | → SQL if tier A/B |
| **SQL** | Qualified opportunity | pain confirmed + budget plausible + DM identified | book discovery |
| **Discovery** | Call/research deep-dive | meeting held, needs documented | → proposal |
| **Proposal** | SOW + pricing sent | proposal delivered, follow-up scheduled | → negotiation |
| **Negotiation** | Terms/concessions | all commercial items agreed | sign + onboard |
| **Won** | Signed + payment | contract executed, onboarding started | start engagement |
| **Lost** | Not moving forward | reason logged | nurture or archive |

## Revenue KPIs

| KPI | Definition | Target |
|---|---|---|
| Booked revenue | Contracted value / month | per plan |
| Win rate | Won ÷ (Won+Lost) | ≥ 30% |
| Avg deal size | Booked ÷ won deals | ≥ $6,000 |
| Sales cycle | Median first-touch → won | ≤ 45 days |
| Lead→SQL | SQL ÷ (A+B leads) | ≥ 35% |
| SQL→Won | Won ÷ SQL | ≥ 25% |
| MRR attach | Deals landing on subscription | ≥ 60% |
| Forecast accuracy | Variance forecast vs actual | ≤ 15% |
| Renewal rate | Retained subscription revenue | ≥ 90% |

## Sales motion (outbound-first, inbound-supported)

1. **Qualification (BANT-lite):** Budget (budget_estimate), Authority (DM identified), Need (pain_points + evidence), Timing (signal recency). Score in CRM.
2. **Discovery:** one 30-min call or async brief; Vector + Quill document needs → proof pack.
3. **Proposal:** generated by Quill from templates + research evidence; pricing from `pricing.md`; bundle attach enforced.
4. **Negotiation:** pre-approved concession ladder; >10% deviation → CEO gate.
5. **Contract:** Legal template (MSA/SOW), sent for e-signature; legally binding → owner executes after agent review.
6. **Onboarding:** handoff to Halo (Client Success) + Kepler (PM) via `03-sales/onboarding-playbook.md`.

## Scheduling

- Discovery calls via Cal.com/Calendly link embedded in emails.
- Availability windows auto-synced to owner's calendar for the rare human-touch call; otherwise AI-led async discovery.

## Compliance in sales

- Every email has physical address + opt-out (CAN-SPAM).
- No false claims, no guaranteed ROI, no fake urgency.
- Pricing deviations logged. Contracts only via approved templates.

## Weekly rhythm

- Daily: pipeline review, follow-ups, reply SLA (< 24h).
- Weekly: pipeline review with Ranger (lead quality) + forecast to COO/CEO.
- Monthly: win/loss analysis, target reset, playbook refresh.
